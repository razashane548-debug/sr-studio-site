Reshu installation and export errors

For the current public v0.3.13-r8 APK. Keep original books and recovery keys safe. Menu names vary by Android device.

Installation blocked

  1. Read the exact Android/Play Protect warning, not just "blocked".
  2. If it identifies the app as harmful, stop. Do not disable protection to bypass that warning. Send the warning text, version and phone model to support, without private files.
  3. If Android instead asks permission to install from this browser/file app, allow only that source if you trust the official download; turn that source permission off after installing.
  4. Read our reviewed Play Protect guidance before any temporary scan-setting change. Re-enable scanning immediately even if installation fails.

Signature conflict or "App not installed"

  1. Confirm Android 6.0 or later and enough free storage.
  2. Download again with the official button; compare file size and SHA-256.
  3. Try installing over the existing official app, not uninstalling first. For a signing conflict, stop and report the exact message. Uninstalling can remove local data and is not our default fix.
  4. Do not use a modified APK or blindly change security settings. No single step fixes every Android installation error.

Encrypted backup or restore failed

  1. Check the selected account, folder access, network and cloud-provider sync.
  2. For setup, save the new recovery key in device Documents, outside the backup folder, then confirm that same file.
  3. For restore, select the .rsbackup file and its matching recovery key, not JSON or a key from another setup.
  4. Do not clear app data to fix it. Keep the files unchanged and report the exact error if it repeats. Read the full backup procedure.

Audio export fails or takes a long time

  1. Keep the original document. Check available storage; exports can be much larger than the source document.
  2. Try a short page/range first to see whether the problem depends on document size or unreadable/scanned pages.
  3. Check that your chosen destination remains writable. If asked, choose a valid save location.
  4. Keep the foreground export running. If you cancel, cleanup may not be immediate.
  5. Whole-book output can have multiple parts, and blank/unreadable pages may be skipped. No MP3 or instant-export guarantee is made.
  6. If it repeats, send app version, phone model, Android version, free-space estimate, export type and error text. Do not send private books or recovery keys.
