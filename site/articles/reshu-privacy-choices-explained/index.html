Privacy

Reshu's privacy choices, explained

By SR Studio

Reshu PDF Reader is free, has no ads, and needs no account. This article lists the app's data choices in plain words, so you can decide what to turn on. The full detail lives in the SR Studio privacy policy (including Reshu).

Off by default

Usage sharing, crash reports and announcements have separate consent controls, and all are off by default. Push notifications are opt-in; messages the app receives can be saved in its notification inbox. App-usage sharing uses Firebase Analytics and is also opt-in. Usage events do not include your book text, but the SDK is not anonymous. Crash reporting uses Firebase Crashlytics in the current v0.3.13-r8 release, with its own opt-in off by default. If enabled, it sends technical failure, device and Android details plus an installation identifier; it is not anonymous. Turning it off deletes unsent reports, not reports already uploaded.

Encrypted backups you control

Reshu can back up your library and bookmark metadata - things like your books, notes and reading positions - encrypted with a recovery key that you keep. Original book files are not included in the backup. A weekly backup option exists if you want it. Restore needs the same key, so store it somewhere safe; if you lose the key, the backup cannot be opened. Saving to a cloud folder depends on the Android file provider you pick.

When data can leave the phone

Some things are outside the app's control. Online speech voices may send reading text to the installed speech provider. System voice search, your chosen file provider, Android's own backup setting, and anything you deliberately share can all move information off the phone. For sensitive documents, use an on-device voice and be deliberate about sharing.

No silent updates

The app checks a version file and shows a notice when a newer version exists. It does not silently download or install updates - installing an update is always your action.

Honest limits

Privacy choices cannot make OCR or translation perfect, and Android itself has settings (like device backup) that apply to every app. Read the privacy page once, set the two opt-in switches the way you want them, and keep your recovery key safe.
