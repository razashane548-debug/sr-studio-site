Website accessibility checks: October 8, 2026

This report describes checks run on October 8, 2026, not a WCAG certification or a claim that every user can use every feature.

Environment and pages

Automated Chromium 154.0.8037.57 on Linux, with axe-core 4.14.0. The revised website was checked before publication at desktop width 1280 pixels, mobile-layout width 320 pixels and 200% CSS zoom. CSS zoom is not the same as every browser's own zoom or Android magnification.

Pages checked: home; Reshu; support; about; accessibility statement; security; changelog; app privacy; website privacy; terms; donate; articles index; backup/restore guide; troubleshooting guide; press kit; Hindi; Urdu; this test report; license.

Measured results

  • Each checked page has one main heading and one main landmark. Every checked link has text or an accessible label; every image has an alt attribute. Attribute presence alone does not prove a description is useful.
  • First Tab reaches the visible skip link. Enter moves focus to main; the following Tab reaches a link in main content. An explicit focusable main target was added after the initial live check changed only the hash.
  • No document-level horizontal overflow was measured at 320-pixel width or at 200% CSS zoom on the checked pages. This does not prove every external service or device works.
  • The WCAG 2 A/AA and 2.1 A/AA axe rule sets returned zero detected violations on the checked pages. Automated rules cover only part of accessibility; zero detected violations is not conformance.

Contrast samples

Download these three contrast samples as CSV

Computed homepage colors, using the WCAG relative-luminance formula: body text #1b2a2e on #fbfaf6, 14.19:1; lead text #46585c on #fbfaf6, 7.15:1; white primary-button text on #0b5f5c, 7.48:1. These are selected samples, not a contrast audit of every state or image.

Visual and keyboard checks

The homepage link sequence was traversed without a mouse. The visible skip-link and link focus outlines were inspected. Rendered Hindi and Urdu layouts, backup guide, press kit and enlarged homepage were inspected for readable text, wrapping and clipping. Urdu uses right-to-left main content and language tags; Navigation labels have since been localized into Hindi and Urdu with matching language and direction tags.

Not tested

No TalkBack, NVDA, VoiceOver or other speech-output session was run for this report. No touch exploration, Braille display, switch control, real Android device, cross-browser audit, complete form-task audit or third-party download-page audit was performed. Translation has not had an independent native-language review. This report is about the website, not a device or security test of the APK.
