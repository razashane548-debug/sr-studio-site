Website accessibility

Updated October 8, 2026.

We aim to make this website usable with screen readers and a keyboard, with readable text and clear links.

What is present

  • A skip-to-main-content link on each page.
  • Named navigation, main content and footer landmarks.
  • A page heading and structured section headings.
  • Text-based instructions and links, without an image-only download button.

Scope and limits

This is not a WCAG conformance certification. We have not completed an independent accessibility audit across all browsers, screen readers and device sizes. WhatsApp is an external service with its own interface. This statement concerns the website, not a certification of the Android app.

Report a barrier

Use Contact, then select "Connect on WhatsApp". Tell us the page address, browser, screen reader and what did not work. Do not send passwords or private documents. No fixed response time is promised.
