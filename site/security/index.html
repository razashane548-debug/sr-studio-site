Report a security issue

Updated October 7, 2026. You can also email contact@srstudio.dpdns.org with subject "Security report".

If you suspect a security problem with this website or the current public Reshu APK, use Contact SR Studio and select "Connect on WhatsApp". Start the message with "Security report". The link opens WhatsApp, where the contact number may be visible.

What to include

  • Affected page or app version and your phone/Android version if relevant.
  • A short description and safe steps that reproduce the issue.
  • The exact warning or error, with personal information removed.

Do not send passwords, recovery keys, private books or another person's data. Do not test against other people's devices, access data that is not yours, disrupt services, or publish private exploit details in public comments.

What this is not

This page is a reporting route, not permission for intrusive testing, a legal safe-harbor promise, or a bug-bounty offer. We do not promise payment or a response deadline.

Installation warnings

Keep Play Protect on and scan first. Do not bypass a harmful-app warning. See the installation and Play Protect guidance.
