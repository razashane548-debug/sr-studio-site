Reshu: what's new

Updated October 13, 2026.

Current public pre-release: Reshu v0.3.13-r8

Released 2026-10-11. Android 6.0 or later. The app displays 0.3.13; version code 15. The -r8 suffix identifies this shrink-only build, not an optimized or obfuscated build.

APK: 75,395,258 bytes (71.9 MiB). SHA-256: 045d5c889ae30bcb66c1e41875c9fda8b65b838c4cc5db6a9ab082a11cb89ae7.

Install the official matching-signature APK over the existing app; do not uninstall first. Back up important documents and records before updating.

Checks recorded for these exact bytes include the CI release build, Semgrep on the last code change, MobSF and manifest/content checks, Firebase Test Lab Robo passes on Android 11, 12, 13 and 16, and reviewed owner-device reading, Back-dialog and TalkBack-settings checks. Known MobSF findings remain. These checks do not prove that the app is free of vulnerabilities or accessible on every device. Robo tests do not cover every import or Back flow.

OCR, translation and reading order can be wrong; voices depend on the phone and installed services. Source code remains private. R8 shrinking does not prevent copying the APK. Pending sound effects and future work are not included in this release.

Historical release: Reshu v0.3.5

Released September 30, 2026. Android 6.0 or later. Version code 8. APK: 77,076,890 bytes (73.5 MiB).

  • English, Hindi, Urdu and Indian Punjabi app text, with compatible pa-IN voice matching for Punjabi.
  • Camera-to-book flow and scanned-page OCR.
  • Consent-based offline translation models for English, Hindi and Urdu.
  • Notes, chapter navigation, quotes, book ratings, vocabulary export and reading goals.
  • Encrypted library/bookmark metadata backup with a separate recovery key. Original books are not included.
  • Whole-book audio export improvements, reading widget and app-lock controls.
  • Separate optional usage-sharing and push-notification choices, both off by default.

September 30 security replacement

The APK was replaced without changing the version name or code. The published release notes report disabled debug/test mode, blocked cleartext traffic, bounded EPUB text, validated shared imports and restricted reminder broadcasts. This was the update advice for that historical release; use the current download above now. A same-version replacement does not trigger a new update notice.

Earlier phone checks predate this replacement. Import/share device regression for the replacement remains pending; these changes are not a safety guarantee.

Known limits

OCR and translation can be wrong. Hindi-Urdu translation uses English as an intermediate. Punjabi translation is not supported; Punjabi/Urdu speech depends on compatible installed voices. Audio cancellation can take up to 30 seconds. A minor "1 books finished" grammar issue remains.
