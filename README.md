# SR Studio website

Static, accessible website intended for Netlify hosting with no build step.

The invite form POSTs to FormSubmit for `qse9pq@mail.instinct.com`. First submission sends an activation email to that address. The form is not operational until its owner confirms the activation. After confirming, submit a synthetic test from the live site and verify arrival at the agent mailbox. CAPTCHA is disabled for accessibility, with FormSubmit's honeypot enabled; the provider may still impose anti-spam limits. Do not promise delivery before end-to-end test.

Canonical URLs and sitemap assume the project URL `https://reshminabuild.netlify.app/`; verify the URL Netlify actually issues before Search Console submission. Search ranking and indexing are not guaranteed. The site's content avoids claiming production availability. Contact phone is only in WhatsApp link target, not visible copy.
