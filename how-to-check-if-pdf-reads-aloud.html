Accessibility guide

Why does my PDF look fine but not read aloud?

A PDF can look like a page of text and still contain only a picture of that page. A screen reader needs text it can access, not just letters visible in an image. This often happens with scanned notes, forms, and books.

Start with a simple check

Open the PDF in a reader you already use. Try to select a sentence, search for a word you can see, or navigate through its text with your screen reader. If none of these works, the page may be an image rather than selectable text. This is a clue, not a diagnosis: a PDF can have other accessibility problems too.

What OCR can and cannot fix

Optical character recognition, or OCR, tries to turn writing in an image into machine-readable text. After OCR, check the result against the original page, especially names, numbers, Urdu text, and tables. A searchable file is not automatically a well-structured one. Headings, reading order, image descriptions, and form labels also matter when someone needs to navigate rather than merely hear words.

If you are sharing a PDF

When you can, export the original document as a tagged, accessible PDF instead of scanning printed pages. Give it a useful title and real headings. If a scan is unavoidable, run OCR, check the text, and ask someone who uses a screen reader to try the file before you send it.
